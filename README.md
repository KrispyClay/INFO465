# INFO465 Assignment 1

## Description
This project is a simple JavaScript program that reads a list of integers from the user and calculates basic statistics.

## Features
- Accepts integer input from the user
- Allows user to type 'q' to quit input
- Calculates:
  - Count
  - Mean
  - Median
  - Minimum value
  - Maximum value
- Includes basic error handling for invalid input
